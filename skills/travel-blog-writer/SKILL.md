# 해외여행 블로그 글쓰기

사용자가 레퍼런스 조사 끝에 고른 스타일로 여행 블로그 초안을 쓴다. 완성 예시는 `references/example-shanghai.md`에 있다. 글을 쓰기 전에 한 번 읽고 톤과 밀도를 맞춘다.

## 확정된 스타일 (레퍼런스 3편 조합)

| 요소 | 기준 | 규칙 |
|---|---|---|
| 구성 | 트립스토어 「서유럽 9박10일 경비 총정리」 | 결론(1인 총액) 먼저 → 항목별 경비 분해(표) → 일차별 일정 → 절약 팁 → 자주 묻는 질문 → 마무리 |
| 사진 | 브런치 「오스트리아 여행① 혼자, 그리고 둘이」 | 소제목마다 장소별 사진 2~3장 묶음, **모든 사진에 한 줄 캡션** |
| 말투 | 브런치 「여자 혼자 유럽 여행 비용 절약 6가지」 | 존댓말 해요체, "제가 해보니~" 경험담 + "~해 보세요" 조언, 이모지 거의 없음 |

## 글 골격

```
# <여행지> <N박M일> 여행 경비 총정리, 1인 <총액>으로 다녀온 코스와 꿀팁

## <여행지> N박M일, 결론부터 말하면 1인 약 OO만 원
  누구와/왜/언제 2~3문장 → 쇼핑 제외 총액을 굵게 → 대표 사진 1장

## 항목별 <여행지> 여행 경비 분해
### 총 예산 요약      ← 표: 항목 | 내용 | 1인 금액 (항공·숙소·식비·현지교통·입장료·기타, 합계 굵게)
### 항공권과 현지 교통 ← 공항→시내 이동법, 사진 2장
### 숙소와 식비        ← 숙소 위치 선택 이유, 하루 식비 감각

## N박M일 일정과 동선
### 1일차: A → B → C   ← 일차마다 사진 2~3장 + 시간·가격 팁 1개 이상
...

## 경비 아끼는 <여행지> 여행 팁   ← ### 소제목 3개 (결제/통신/교통 등 현지 특화)

## 자주 묻는 질문      ← **Q.** 비자·입국 / 환전 금액 / 추천 시기 (3개)

## 마무리              ← 한 줄 총평 + "OO만 원 안팎이면 이 일정 참고하셔도 충분해요" + 마지막 사진
```

분량은 약 4,000~5,000자, 사진은 15~20장이 기준이다.

## 작업 순서

1. **자료 받기**: 여행지·기간·동행, 경비 내역, 일차별 장소, 사진 유무를 묻는다. 사용자가 "랜덤으로" 하라고 하면 현실적인 예시로 채우되, 맨 위에 `> ⚠️ 초안 안내: 일정·경비·장소는 예시로 만든 내용입니다…` 블록을 넣는다.
2. **초안 쓰기**: 위 골격대로 쓴다. 사진 자리는 먼저 `[사진: 장면 설명]` + 다음 줄에 `*캡션*`으로 잡는다. 가격·환율·입국 정책은 확인되지 않았다면 FAQ나 안내 블록에 "출발 전 최신 정보 확인"을 남긴다.
3. **사진 채우기** (사용자 사진이 없을 때):
   - 사진 자리마다 영어 검색어 2개를 담은 spec.json을 scratchpad에 만든다. 파일명은 `01_bund_night`처럼 번호_장면으로 한다.
   - `python -I scripts/fetch_commons_images.py <spec.json> <글폴더>/images`를 실행한다. Wikimedia Commons의 CC0, CC BY, CC BY-SA, 퍼블릭 도메인 사진만 받는다. 429가 나도 스크립트가 알아서 기다렸다 재시도하고, 다시 실행하면 이미 받은 사진은 건너뛴다.
   - `python -I scripts/contact_sheet.py <images> <scratchpad>/sheet.jpg`로 미리보기를 만들어 **직접 눈으로 본다** (Pillow가 없으면 `pip install pillow`).
   - 장면과 무관한 사진(다른 나라, 다른 장소, 동명이인 사물 등)은 지운다. `_credits.json`에서도 빼고, 원본 제목(`File:…`)을 `images/_rejected.json` 리스트에 넣은 뒤 다른 검색어로 다시 실행한다. 끝내 못 찾으면 `[사진: … → 직접 찍은 사진으로 교체]` 자리 표시로 되돌린다. 예: "Harpa"를 검색했더니 조개 속(屬) 사진이 나옴. 사진이 장면과 조금 다르면 **캡션을 사진에 맞게 고친다**. 예: 전망대에서 찍은 사진이 아니면 "강 건너에서 본 상하이타워".
   - 자리 표시를 아래 형식으로 바꾼다.
     ```
     ![](images/01_bund_night.jpg)
     <sub>사진: 작가 / 라이선스 (Wikimedia Commons)</sub>
     *캡션*
     ```
   - 안내 블록에 "사진 출처 표기를 지우지 마세요(전체 목록: images/_사진출처.md)"를 덧붙인다.
4. **교정**: 사용자에게 말투(더 친근하게/짧게/이모지)와 그림(사진 수, 캡션 톤)에서 고칠 점을 묻고 반영한다.

## 주의

- 네이버 블로그(blog.naver.com)는 웹 검색과 페이지 읽기가 막혀 있다. 우회하지 말고, 사용자에게 본문을 붙여넣어 달라고 하거나 브런치·여행사 블로그 등 접근 가능한 곳을 쓴다.
- 남의 사진을 쓸 때 1인칭 캡션("제가 찍은~")은 출처 표기와 함께 둔다. 실제 발행 때는 본인 사진으로 바꾸도록 안내한다.
- 결과물은 사용자 작업 폴더에 `<여행지>_<N박M일>_블로그초안.md` + `images/` 폴더로 저장한다.
